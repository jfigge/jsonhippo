JsonHippo

A JSON viewer that tells you exactly where it broke. “Invalid JSON” is useless when the input is five megabytes long. JsonHippo's parser is written by hand, character by character, so when it fails it says where — line, column, what it expected, what it found, and the path to it: Line 123982, col 9: expected ',' or '}' but found string "zip" (in $.people[4321].address). Click that and the caret lands on the bad character. It also unescapes the JSON that APIs and logs hand back as a string, and its tree can be filtered.

Why it exists

Three things other JSON viewers cannot do

JsonHippo is not trying to replace the viewer you already use. It exists for the three moments where that viewer gives up on you.

Pinpoint errors

It says where it broke — and takes you there

One missing comma, 124,000 lines into a 5 MB file. JsonHippo reports the line and column of the token after the gap, what it expected, what it found, and the JSON path of the object it was in. The line is marked in the gutter; one click selects the bad token and scrolls it into view.

A file missing its last } points at the brace that was never closed — not at the end of the file, which says nothing. A ] closing a { links back to where that { was opened.

Smart paste

Escaped JSON, unescaped on paste

APIs and logs return JSON as a string: "{\"id\":4321,\"event\":…}". Paste one and JsonHippo recognises it, unescapes it — twice, if it was escaped twice — and parses the result. It works on the bare form copied out of the middle of a log line, too.

It never changes your text silently: a notice says what it did, and Undo puts back exactly what you pasted. Ordinary JSON with \" inside its strings is never touched.

jsonhippo.com
Filterable tree

A tree you can actually search

Type zip and the tree narrows to every zip in the document, each with the chain of objects that leads to it, and everything else folded away. Match keys, values or both; make it case-sensitive; use a regular expression; or type a path like $.people[*].address.zip.

The search runs over the whole document, not just the part on screen, so nothing hidden in a collapsed branch is missed. Step through the matches with Enter. Press Esc and the tree is back exactly as it was.

Also included

The everyday tools, done carefully

Format and minify

Written out from the parse tree, not round-tripped through JavaScript values, so 12345678901234567890 keeps every digit and keys stay in their original order — duplicates included, and flagged.

Copy path, copy value

Select any node to see its path. Copy the path, copy that subtree formatted, or jump to where it sits in the text.

Large files

A 5 MB document parses in under a tenth of a second. The tree draws only what is open, starting from its first level, and the filter searches every node of it in a fraction of a second.

Hints that know the usual suspects

Comments, single quotes, trailing commas, True for true, curly quotes from a word processor, and the invisible no-break space a chat app slipped in — each is named for what it is.

Nothing leaves your machine

A static page: no server, no account, no tracking. Files you load are read in the browser and never uploaded.

Keyboard first

/ to filter, Enter for the next match, arrow keys through the tree, Ctrl+Enter to format. Light and dark themes follow your system.

Credit

Standing on a favourite

JsonHippo is inspired by jsonviewer.stack.hu, the online JSON viewer its author has used for years. Its tree view is the part of that tool this one most wanted to keep — and to be able to filter.
